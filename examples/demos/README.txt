Desktop demonstrations
======================

These programs are the readable sources behind the Demos menu. They progress
from a single moving object toward animation, interaction, simulation, and
virtual-chipset techniques.

  bouncing_ball.py  Animation loop, velocity, collision, and double buffering
  paint.py          Pointer events and direct drawing
  keyboard.py       Key codes, text input, and modifiers
  rainfall.py       Many independently animated objects
  life.py           A cellular automaton and grid updates
  starfield.py      Depth, projection, and palette effects
  plasma.py         Procedural colour and scanline effects
  mandelbrot.py     Incremental computation and visualization
  spirograph.py     Parametric curves
  sprites.py        Virtual Amiga sprite channels

Open a demo from the Demos menu, then use View > Source (or F4) to inspect,
edit, save, and reload the same source while PythonOS is running.
